Detailed Accessibility Compliance Audit (WCAG 2.1)

Compliance Level: WCAG 2.1 Level AA | Team: Team Artisant | Class: 4TWIN1 | Date: May 4, 2026

1. Executive Summary

This document presents a comprehensive accessibility audit of the BuildMarket platform. Our goal was to achieve and maintain **WCAG 2.1 Level AA** compliance, ensuring that the BTP ecosystem is inclusive for all professional users, including those with permanent or temporary disabilities.

The audit covered four primary domains: visual, motor, auditory, and cognitive. As of the current release, the platform successfully meets all Level A and AA criteria across its core user journeys (Sign-up, Marketplace Browsing, Quote Management, and 3D Visualization).

2. Audit Methodology

We employed a rigorous "Hybrid Audit" approach, combining automated scanning with qualitative human testing:

  • Automated Scanning: Axe-core engine and Lighthouse Accessibility audits were run on every production build.
  • Screen Reader Testing: Tested using NVDA (Firefox) and VoiceOver (Safari/Chrome) to ensure meaningful navigation for visually impaired users.
  • Keyboard-Only Navigation: Verified that every interactive element is reachable and actionable without a mouse.
  • Color Contrast Verification: Manual checks using the Contrast Ratio tool for all branding and UI elements.

3. Principle-by-Principle Analysis

3.1 Principle 1: Perceivable

Information and user interface components must be presentable to users in ways they can perceive.

1.1.1 Non-text Content (Level A) All functional images and icons (e.g., Delete, Edit, Cart) have been verified to contain descriptive aria-label or alt text. Decorative images use empty alt="" to be ignored by screen readers.
1.4.3 Contrast (Minimum) (Level AA) All text elements meet the 4.5:1 ratio. Large text (H1, H2) meets the 3:1 ratio. We adjusted our primary "Slate" and "Teal" colors to satisfy these requirements.

3.2 Principle 2: Operable

User interface components and navigation must be operable.

2.1.1 Keyboard (Level A) The entire Marketplace and Artisan Dashboard are fully keyboard-navigable. This includes the complex 3D viewer, which can be controlled via standard keyboard shortcuts.
2.4.3 Focus Order (Level A) Focus follows a logical sequence (Left-to-Right, Top-to-Bottom). We implemented a Skip to Main Content link for screen reader and keyboard users.

3.3 Principle 3: Understandable

Information and the operation of the user interface must be understandable.

3.3.1 Error Identification (Level A) Form validation errors (e.g., in the Quote Request form) are clearly identified with text descriptions, not just color changes, ensuring users with color blindness can correct errors.

6. Continuous Improvement Roadmap

While we have achieved Level AA compliance, we are committed to further enhancements:

  • Level AAA Contrast: Moving towards a 7:1 ratio for critical information.
  • Dynamic Motion Reduction: Respecting the prefers-reduced-motion media query across all Framer Motion animations.
  • Cognitive Load Reduction: Simplifying complex technical jargon in the Artisan Dashboard.
